# このチャプターで行うこと
このチャプターでは、ピンボールゲームのステージを完成させます。
- ヒエラルキーでゲームオブジェクトを作成する
- ゲームオブジェクトの移動、サイズ変更、角度変更
- ゲームオブジェクトにコンポーネントをアタッチ
ここまで学んできたことを思い出して、ゲームオブジェクトを作る、配置する、コンポーネントをアタッチする、一連の流れをストレスなく行えるまで手に覚えこませましょう。

# その他のコンポーネント
ここまで使ってきたものコンポーネント、それ以外にテンプレートに入れているコンポーネントを紹介します。ここで文章省略のために、「自身」としているところは、「そのコンポーネントをアタッチしたオブジェクト」と読んでください。
- RigidBody2D：自身に物理演算を適用する
- CircleCollider2D：自身に円形の衝突判定を適用する
- BoxCollider2D：自身に四角形の衝突判定を適用する
- AudioSource：自身に音を再生する機能を与える
- RotateScript：自身に、自身が回転し続ける振る舞いを与える
- PlaySoundScript：自身に何かが衝突したときに、自身にアタッチされているAudioSourceコンポーネントを再生する
- CatapultScript：自身に衝突したオブジェクトに対して、上方向の力を加える、加える力はオブジェクトのサイズによって変わる
- AddGravityPressSpaceScript：スペースキーを押したときに、自身がRigidBody2Dコンポーネントを持っていたら、そのGravityScaleを1にする（つまり、落下するようになる）

ここからは未使用のコンポーネント
- AddForceBlockScript：自身に衝突したオブジェクトに対して力を加える。加える力はx, yの2軸で指定可能。
- AddForceBlockToFowardScript：自身に衝突したオブジェクトに対して、自身の右方向の力を加える
- ChangeColorScript：自身に何かが衝突したときに、自身の色を指定された色に変える（自身のSpriteRendererコンポーネントのColorの値を変更する）
- ChangeImageScript：自身に何かが衝突したときに、自身の画像を指定された画像に変更する（自身のSpriteRendererコンポーネントのSpriteを変更する）
- RotateAtOnceScript：自身に何かが衝突したときに、指定された角度だけ回転する。RotateScriptコンポーネントとは違い、衝突した時に一度だけ回転する。

ここで紹介してきたコンポーネントについて注意があります。
この中でUnityに標準で組み込まれているコンポーネントは、RigidBody2D、CircleCollider2D、BoxCollider2Dの3つだけです。他のコンポーネントは最初にインポートしたテンプレートに含まれていたもので、インポートしないと使うことが出来ません。

区別するために、全てに～～Scriptと付けています。これらは、C#というプログラミング言語で記述されたスクリプトファイルで、自分でカスタムしたコンポーネントを作ることが出来ます。

## スクリプトファイルを見てみよう
一つ、スクリプトファイルを開いてみましょう。
プロジェクトウィンドウで[Assets]⇒[Scripts]⇒[Tutorial01]と開いて、[RotateScript]をダブルクリックしてみてください。
![](https://storage.googleapis.com/zenn-user-upload/ed947e7fb75f-20240229.png)

RotateScriptに記述されている内容を見ることが出来ます。
※何か書き込んでエラーを出さないように気を付けましょう。
![](https://storage.googleapis.com/zenn-user-upload/4ff659d9e101-20240229.png)

このスクリプトはこのチュートリアル用に用意したもので、作成時に自動で生成されるコードを除けば、書いたコードは10行目と20行目の２行だけです。1行2行程度のプログラムでも、案外色々なことが出来ます。

最終的に、
自分のしたいことに合わせて、
それを実現可能なスクリプトを書いて、カスタムコンポーネントを作り、
それをゲームオブジェクトにアタッチして様々な振る舞いを実現する。

今はまだ意味が分からないかも知れませんが、チュートリアルを進めるうちにスクリプトを自分で作って書けるようになっていきます。（自分でカスタムコンポーネントを作れるようになったら初心者卒業です）

自分でスクリプト（プログラム）を書くことが出来るようになると、Unityで出来ることの幅が大きく広がります。しかし、まずはゲームオブジェクトの振る舞いを決めているのがコンポーネントであり、アタッチするコンポーネントの組み合わせによってゲームオブジェクトが様々な振る舞いを取っていることを理解しましょう。

# ピンボールゲームを完成させよう
では、他のコンポーネントも使って、ピンボールゲームを作りこんでいきましょう。
その前に、作業を楽にするための豆知識をいくつか紹介します。

## ゲームオブジェクトの階層化
ゲームオブジェクトが増えてくると、管理が大変になりますね。
壁やクギなど、同じカテゴリのゲームオブジェクトはまとめて管理することが出来ます。
![](https://storage.googleapis.com/zenn-user-upload/3d0a621fa03a-20240229.png)

ヒエラルキーに空のゲームオブジェクトを一つ追加します。
＋ボタン⇒Create Empty
![](https://storage.googleapis.com/zenn-user-upload/2ee598d53764-20240229.png)

出来たゲームオブジェクトの名前を変更して、分かりやすくします。フォルダーを作るイメージです。
そして、空のゲームオブジェクトに同じカテゴリのゲームオブジェクトをドラッグ＆ドロップします。これでまとめていくとヒエラルキーをすっきりさせることが出来ます。
![](https://storage.googleapis.com/zenn-user-upload/71478dff75e4-20240229.png)

折りたたむとかなり見やすくなりますね。
![](https://storage.googleapis.com/zenn-user-upload/5a3d19384fff-20240229.png)

## ゲームオブジェクトの複製
既にヒエラルキーにあるゲームオブジェクトは、コピーすることが出来ます。
ゲームオブジェクトをコピーするには、コピー元にしたいゲームオブジェクトを選択してCopyし、ヒエラルキー上の何もない場所を右クリックして、Pasteをクリックします。

![](https://storage.googleapis.com/zenn-user-upload/cf6274f78e50-20240229.png)
![](https://storage.googleapis.com/zenn-user-upload/d1ee20346f4e-20240229.png)

複製を作成する場合には、Duplicateを選べばコピーとペーストが同時に行えます。
![](https://storage.googleapis.com/zenn-user-upload/6e9d1017762e-20240229.png)

複製やコピーしたオブジェクトは、元のオブジェクトに重なっている状態になっているので、位置を動かしてあげましょう。

コピーしたオブジェクトには、元のオブジェクトと同じコンポーネントがついている状態になります。

## Spriteに画像を貼り付ける
Spriteコンポーネントを持つオブジェクト（Sprite⇒Circle等で作成したオブジェクト）には、画像を貼り付けることが出来ます。

インスペクターのSprite RendererのSpriteの場所（下の画像でSquareとなっている場所）に、画像をドラッグ＆ドロップします。
![](https://storage.googleapis.com/zenn-user-upload/a273689efc7e-20240229.png)

これで画像を表示することが出来ました。
音声ファイルをインポートしたときと同じようにして、画像ファイルをインポートすれば、自分の好きな画像をゲーム中に登場させることが出来ます。

ChangeImageScriptコンポーネントを使用する場合には、インスペクターのChangeImageScriptコンポーネントのChangeSpriteにも画像を設定しておく必要があります。
（何かが衝突したら、設定した画像に切り替わる）
![](https://storage.googleapis.com/zenn-user-upload/21a139b0db23-20240229.png)

## 背景BGMを流す
ゲーム中、好きな音楽を再生したい場合は、適当なゲームオブジェクトにAudioSourceコンポーネントをアタッチして、AudioClipに再生したい音楽を設定します。
Play On AwakeとLoopのチェックを入れておけば、ゲーム開始時からゲーム終了まで同じ音楽をループ再生することが出来ます。もちろん、BGMとして再生する音声ファイルはある程度長いものを選びましょう。

![](https://storage.googleapis.com/zenn-user-upload/88a8978e9e85-20240229.png)

# しっかり完成させよう
出来ることに制限がある状態ですが、今あるコンポーネントを組み合わせるだけでも面白いものに出来るはずです。中途半端で終わらせるのではなく、他の人に遊んでもらえるようにしっかり作りこんでみましょう。

# おわりに
Unityでの最初のゲーム完成、おめでとうございます。
出来ることがまだ少なくて、満足のいく出来にはならないかもしれません。
例えば、得点が入らない、一回弾を発射したら終わってしまう、パドルのように上下に動く動きをさせたい、、、色んな不満が出てくると思います。

出てきた不満をメモしておいて、後でもう一度このピンボールゲームに戻ってみましょう。スクリプトを書いてカスタムコンポーネントを作る、これが出来るようになってから戻ってくれば、もっといいゲームに出来るはずです。
