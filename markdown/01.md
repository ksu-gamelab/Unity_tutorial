# UnityHubをインストール
## ダウンロード
下記サイトからUnityHubをダウンロード
https://unity.com/ja/download

![](https://storage.googleapis.com/zenn-user-upload/dd78f8cb30da-20240425.png)

## UnityHubを起動、アップデート
アップデートがあったら、最新版に更新しておく
![](https://storage.googleapis.com/zenn-user-upload/bd257b94c38b-20240425.png)

環境設定を開く
![](https://storage.googleapis.com/zenn-user-upload/32097ea63bd4-20240425.png)

言語設定を日本語に変更（してもしなくてもいい）
![](https://storage.googleapis.com/zenn-user-upload/e50134f7a82a-20240425.png)

## Unityアカウントを作成してサインイン
![](https://storage.googleapis.com/zenn-user-upload/96d405252b9a-20240425.png)

Google、FaceBook、AppleID等でサインインするか、こちらでIDを作成からアカウントを作成してサインインする。
![](https://storage.googleapis.com/zenn-user-upload/ad10a46e6073-20240425.png)

![](https://storage.googleapis.com/zenn-user-upload/12876328415f-20240425.png)

「Get Unity Personal」が表示されたら「Agree」をクリック
![](https://storage.googleapis.com/zenn-user-upload/19d602932dd6-20240425.png)

## Unityエディターをインストール
[LTS]とついているものを選択。
![](https://storage.googleapis.com/zenn-user-upload/30ef43aafc9f-20240425.png)

インストールをクリック
Microsoft Visual Studio Community が無ければチェックを入れる。
その他は必要に応じて、後で変更可能。Language Packの日本語は入れても入れなくても構わないが、このチュートリアルでは英語版で進める（日本語メニューより英語メニューの解説サイトが多いため）
![](https://storage.googleapis.com/zenn-user-upload/4a612ca45909-20240425.png)

インストール終了まで待つ（1時間以上かかることもあります）。
UnityHubが最新出ない場合、インストールに失敗することがあるので、UnityHubは必ずアップデートしてから行ってください。
![](https://storage.googleapis.com/zenn-user-upload/03a1d6fb2d5e-20240425.png)

インストール完了後、[Visual Studio Installer]を起動
![](https://storage.googleapis.com/zenn-user-upload/60c840f7d75e-20240425.png)

Visual Studio Commusity 2022の[変更]
![](https://storage.googleapis.com/zenn-user-upload/d268893868d2-20240425.png)

C++によるデスクトップ開発
![](https://storage.googleapis.com/zenn-user-upload/477ddcf60543-20240425.png)

Unityによるゲーム開発、C++によるゲーム開発　にチェックを入れる
![](https://storage.googleapis.com/zenn-user-upload/b77cab2d0591-20240425.png)

右側の、インストールの詳細で、[Windows 11 SDK]のチェックを入れる
![](https://storage.googleapis.com/zenn-user-upload/a3a1e66b61e4-20240425.png)

[変更]をクリックして、変更をインストール

以上でUnity起動前の設定は完了です。
