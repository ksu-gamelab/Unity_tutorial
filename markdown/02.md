# このチュートリアルで作成するゲーム
Unityを使用して手軽に楽しめる2Dピンボールゲームを作成する方法を紹介します。
このチュートリアルでは、基本的なUnityの操作方法を学び、Unityにおけるゲーム開発の基本を身に付けます。
![](https://storage.googleapis.com/zenn-user-upload/8bdffe557399-20240227.png)

# このチャプターで行うこと
このチャプターでは、Unityプロジェクトを作成してテンプレートファイルをインポート、ピンボールゲームを作るための下準備を行います。

# 要点
Unityでのゲーム開発にあたって、最初に理解するべきことはGameObject(ゲームオブジェクト)とComponent(コンポーネント)の関係性だと思います。このチュートリアルでは、ゲームシーン内にゲームオブジェクトを配置し、ゲームオブジェクトにコンポーネントを付けることで、ゲームオブジェクトが様々な振る舞いを獲得することを学びます。

# プロジェクトを作成する
Unityで2Dプロジェクトを作成しましょう。以下の手順でプロジェクトを作成してください。
- UnityHubを起動し、[New projyect] ボタンから新規プロジェクトを作成
![](https://storage.googleapis.com/zenn-user-upload/b005ef214400-20240227.png)

![](https://storage.googleapis.com/zenn-user-upload/b20d8d6864dc-20240227.png)

# テンプレートファイルをインポート
下記のリンクから、今回のテンプレートファイルをダウンロードしてください。
https://github.com/ksu-gamelab/Unity_tutorial/raw/main/UnityTutorial_01.unitypackage

ダウンロードしたファイル（UnityTutorial_01.unitypackage）を、インポートします。
- プロジェクトウィンドウ内の何もない場所を右クリック
![](https://storage.googleapis.com/zenn-user-upload/38f47de047be-20240227.png)
- Import Package ⇒ Custom Package とクリック
![](https://storage.googleapis.com/zenn-user-upload/201096aabf94-20240227.png)
- ファイルを選択して開く
![](https://storage.googleapis.com/zenn-user-upload/d490b6591cc5-20240227.png)
- Inport Unity Package ウィンドウが開くので、 [Import]ボタンをクリック
![](https://storage.googleapis.com/zenn-user-upload/be7026a9846c-20240227.png)
- 警告が出てくるので、 [Reload]
![](https://storage.googleapis.com/zenn-user-upload/41a16297bfc4-20240227.png)
- プロジェクトウィンドウに3つのフォルダが見えたらインポート完了
![](https://storage.googleapis.com/zenn-user-upload/8dc47af32d8a-20240227.png)

![](https://storage.googleapis.com/zenn-user-upload/81de09e3c01b-20240227.png)

ここまで出来たら、次のチャプターに進みましょう。
